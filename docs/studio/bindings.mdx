# اتصال widget به دیتاستریم

binding باید به یک datastream موجود در context محصول وصل شود؛ شناسهٔ ساختگی یا
کلید تایپی که در catalog نیست، binding معتبر نیست.

## نمونهٔ مفهومی

```json
{
  "widget": "temperature-card",
  "source": {
    "type": "datastream",
    "key": "temperature"
  },
  "display": {
    "unit": "°C",
    "precision": 1
  }
}
```

برای فرمان، control باید به دیتاستریم writable وصل باشد و نتیجهٔ accepted،
rejected یا failed را به کاربر نشان دهد. مقدار cache را به‌جای confirmation
موفقیت فرمان نمایش ندهید.
