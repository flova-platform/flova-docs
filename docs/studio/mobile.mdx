یک dashboard منتشرشده در Studio برای runtime موبایل طراحی می‌شود، نه برای یک
صفحهٔ ثابت دسکتاپ. PWA در مرورگر اجرا می‌شود و می‌تواند روی صفحهٔ اصلی گوشی
نصب شود. اپ Android یک بستهٔ نصب‌شدنی است و قابلیت‌هایی مثل دوربین و Bluetooth
را در اختیار host موبایل می‌گذارد.

## استفاده از PWA

1. `https://pwa.flova.ir` را در مرورگر باز کنید.
2. وارد حساب شوید.
3. اگر مرورگر پیشنهاد نصب داد، Add to Home Screen را انتخاب کنید.
4. dashboard منتشرشده و دستگاه مجاز را باز کنید.
5. برای provisioning، دسترسی‌های لازم را بدهید و مراحل اتصال Wi-Fi را دنبال کنید.

PWA برای صفحه و داده به اینترنت نیاز دارد، اما shell و cache می‌تواند آخرین
تجربهٔ ذخیره‌شده را تا زمان برگشت اتصال نگه دارد. وضعیت زنده و فرمان موفق را
فقط وقتی قطعی بدانید که runtime نتیجه را دریافت کرده باشد.

## نصب Android

فایل APK رسمی باید از release عمومی همان نسخه نصب شود. [دانلود APK نسخهٔ منتشرشدهٔ
1.0.0](https://storage.flova.ir/flova-assets/releases/android/1.0.0/flova-app-1.0.0.apk)
ممکن است هنگام نصب، اجازهٔ نصب از این منبع را فعال کنید. پیش از نصب نسخه‌های
بعدی، نام نسخه و checksum منتشرشده را با release همان نسخه مقایسه کنید و فقط از
منبعی استفاده کنید که تیم Flova معرفی کرده است. نسخهٔ توسعه را با اپ رسمی
اشتباه نگیرید؛ development client برای توسعه است و جای release عمومی را
نمی‌گیرد.

## provisioning در موبایل

در SoftAP، اپ از صفحهٔ setup محلی دستگاه handoff را می‌فرستد. در BLE، اپ دستگاه
BLE را پیدا می‌کند، handoff و Wi-Fi را تحویل می‌دهد و سپس دستگاه به اتصال عادی
برمی‌گردد. اگر اتصال خودکار Wi-Fi در نسخهٔ Android یا مرورگر ممکن نبود، شبکهٔ
`Flova-Setup-*` را دستی انتخاب کنید و به اپ برگردید.

صفحهٔ [provisioning Console](/docs/console/provisioning) مراحل activation را
و [provisioning SDK](/docs/sdk/provisioning) مرزهای firmware سفارشی را توضیح می‌دهد.

## اعلان‌های دستگاه

بعد از claim شدن دستگاه، فلووا یک اعلان برای کاربر ارسال می‌کند. وقتی دستگاه
برای اولین بار پیکربندی معتبر را گزارش کند و آمادهٔ استفاده شود، اعلان جداگانهٔ
دیگری ارسال می‌شود. ایمیل کانال اصلی است و در صورت در دسترس نبودن ایمیل تأییدشده
یا خطای ارسال، پیامک به شمارهٔ تأییدشده ارسال می‌شود.

هر اعلان یک دکمه برای باز کردن همان دستگاه در PWA و یک لینک به همین راهنما دارد.
اگر لینک دستگاه را با `device_id` دریافت کردید، پس از ورود فقط همان دستگاه مجاز
باز می‌شود؛ لینک نامعتبر به فهرست دستگاه‌ها برمی‌گردد. دسترسی دستگاه از سمت
Engine بررسی می‌شود و داشتن لینک به‌تنهایی مجوزی ایجاد نمی‌کند.
