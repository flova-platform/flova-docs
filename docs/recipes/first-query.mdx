# اولین query

پس از online شدن دستگاه، catalog را ببینید و سپس با یک بازهٔ محدود query کنید:

```sql
SELECT time, value
FROM telemetry
WHERE datastream.key = 'temperature'
  AND time > now() - 1h
ORDER BY time DESC
LIMIT 100
```

اگر خطای retention یا time range گرفتید، بازه و aggregation را با entitlement
سازمان هماهنگ کنید. اگر نوع datastream عددی نیست، `avg` و `sum` معتبر نیستند.
