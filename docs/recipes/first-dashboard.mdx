# اولین داشبورد

1. یک صفحه با هدف «کنترل و مشاهده» بسازید.
2. یک widget مقدار را به `temperature` bind کنید.
3. یک control را به `relay` writable وصل کنید.
4. حالت loading، stale، offline و rejected را بررسی کنید.
5. در موبایل و دسکتاپ preview بگیرید و سپس publish کنید.

دادهٔ آزمایشی را با مقدار ساختگیِ بدون برچسب live نمایش ندهید؛ اگر دستگاه هنوز
مقدار ندارد، حالت empty را شفاف نشان دهید.
