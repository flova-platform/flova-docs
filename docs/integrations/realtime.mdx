# Realtime

برای WebSocket ابتدا یک ticket کوتاه‌عمر بگیرید. ticket جایگزین scope REST
نیست؛ capability آن باید جداگانه معتبر باشد.

```json
{"type":"subscribe","channel":"datastream","device_id":"DEVICE_ID","key":"temperature","request_id":"REQUEST_ID"}
```

اتصال عمومی browser و clientهای سازمانی از JSON روی `/api/v1/realtime` استفاده
می‌کند. مسیر binary Device Link برای خود دستگاه است و با این قرارداد یکی نیست.

پیام‌های `subscribe`، `unsubscribe` و `ping` را با `request_id` قابل‌پیگیری
بفرستید و در قطع اتصال، backoff و resubscribe کنترل‌شده داشته باشید.
