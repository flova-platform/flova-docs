# Automation و Schedule

Automation برای واکنش به رویداد یا مقدار دیتاستریم است؛ Schedule برای اجرای
رفتار در زمان‌های مشخص. هر دو در نهایت باید یک فرمان معتبر روی دیتاستریم
قابل‌نوشتن ایجاد کنند.

## قاعدهٔ امن

- trigger باید خواندنی و action باید نوشتنی باشد.
- handler فریم‌ور باید safety را دوباره بررسی کند.
- مقدار را قبل از اجرا با نوع دیتاستریم validate کنید.
- اجرای تکراری را با idempotency و وضعیت run قابل‌پیگیری کنید.

نمونهٔ مفهومی:

```text
temperature > 30°C
        ↓
write fan = true
```

Automation جایگزین safety فیزیکی نیست. interlock، حد حرارتی و حالت fail-safe
باید در خود دستگاه نیز وجود داشته باشد.
