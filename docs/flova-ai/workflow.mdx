# گردش‌کار امن FlovaAI

برای تغییرات واقعی، این چرخه را حفظ کنید:

```text
Inspect → Propose → Review → Apply → Audit
```

1. **Inspect**: مدل‌ها، دیتاستریم‌ها و bindingهای موجود خوانده می‌شوند.
2. **Propose**: تغییر پیشنهادی با نام، شناسه و دلیل روشن ساخته می‌شود.
3. **Review**: انسان diff و اثر تغییر را می‌بیند.
4. **Apply**: فقط تغییرهای تأییدشده و معتبر اعمال می‌شوند.
5. **Audit**: نتیجه و خطا برای پیگیری ثبت می‌شود.

در صورت نبودن context کافی، پاسخ درست «اطلاعات بیشتری لازم است» است؛ ساختن
یک datastream یا ID خیالی پاسخ قابل‌قبول نیست.
