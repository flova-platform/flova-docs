# نمونه‌درخواست‌های FlovaAI

درخواست را با نام واقعی محصول و هدف روشن بنویسید:

```text
در محصول «کنترلر گلخانه»، دیتاستریم‌های موجود را بررسی کن و بگو کدام‌یک
برای نمایش دمای فعلی خواندنی هستند. چیزی ایجاد نکن.
```

```text
برای دیتاستریم موجودِ `pump` یک automation پیشنهاد بده که وقتی
`humidity` کمتر از 30 شد آن را روشن کند. قبل از اعمال، diff و محدودیت‌های safety
را نشان بده.
```

```text
در داشبورد فعلی، binding سنسور دما را پیدا کن و یک کارت نمایش مقدار با واحد
درجهٔ سانتی‌گراد پیشنهاد بده. فقط از منابع موجود استفاده کن.
```

برای تغییرات مهم از عبارت‌های «پیشنهاد بده»، «چیزی ایجاد نکن» و «قبل از اعمال
diff را نشان بده» استفاده کنید.
