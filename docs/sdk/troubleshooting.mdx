# عیب‌یابی SDK

## header پیدا نمی‌شود

environment و dependency را بررسی کنید، header متناسب با board را انتخاب کنید
و cache PlatformIO را دوباره بسازید.

## build موفق است اما upload شکست می‌خورد

کابل data، پورت سریال، دسترسی کاربر و کلید BOOT را بررسی کنید. خطای permission
پورت به معنی خراب‌بودن SDK نیست.

## دیتاستریم مقدار ندارد

کلید را حرف‌به‌حرف مقایسه کنید، پیش از `read()` مقدار `hasValue()` را بررسی کنید،
`onRead()` را ثبت کنید و `reasonCode` مربوط به `refresh()` را بخوانید.

## فرمان اجرا نمی‌شود

ثبت `onWrite()`، نوع مقدار، active level، GPIO و safety condition را بررسی کنید.
نتیجهٔ `FlovaWriteResult` را log کنید، نه credential یا payload خام را.

## دستگاه ناپایدار است

`run()` را مرتب صدا بزنید، `delay` طولانی را حذف کنید، sensor را با interval
بخوانید و allocationهای بزرگ و نامحدود روی ESP8266 نسازید.
