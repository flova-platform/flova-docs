# بردهای سفارشی

هستهٔ قابل‌حمل به چهار سرویس از طرف برنامهٔ شما نیاز دارد:

- `Link` برای transport و صف‌کردن پیام‌های bounded
- `Storage` برای state و credentialهای تحت مالکیت runtime
- `Clock` برای زمان معتبر و timeout
- `Logger` برای گزارش بدون دادهٔ حساس

```cpp
auto relay = device.datastream<bool>("relay");
relay.onWrite(setRelay);
relay.report(readRelay());
device.run();
```

callback شبکه نباید مستقیماً GPIO را تغییر دهد؛ work را queue کنید و در loop
مالک برد، handler را اجرا کنید. برای نمونهٔ buildable به example رسمی
`custom-board-basic` در repository firmware مراجعه کنید.
