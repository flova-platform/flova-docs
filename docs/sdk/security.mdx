# امنیت و safety فریم‌ور

- credential، token و رمز Wi‑Fi را در source یا log قرار ندهید.
- خروجی را فقط از مسیر `onWrite()` تغییر دهید.
- پایهٔ خطرناک را پیش از network و SDK در وضعیت safe قرار دهید.
- loop و callback را blocking نکنید.
- factory reset را پشت نگه‌داشتن طولانی دکمه یا تأیید روشن کاربر قرار دهید.
- برای TLS از transport رسمی SDK و certificate validation استفاده کنید.

```cpp
FlovaWriteResult setHeater(bool enabled) {
  if (enabled && temperature.read() > 70.0) {
    return FlovaWriteResult::reject("over_temperature");
  }
  return hardwareSetHeater(enabled)
    ? FlovaWriteResult::accept()
    : FlovaWriteResult::failure("hardware_write_failed");
}
```

نام شبکه، token، URL خصوصی و payload کامل را در `reasonCode` قرار ندهید.
