# مفاهیم پایه

فلووا بین «تعریف محصول» و «اجرای دستگاه» مرز روشنی دارد. تغییر در تعریف یک
محصول، تا وقتی نسخه‌ای منتشر نشده، نباید رفتار دستگاه‌های منتشرشده را بی‌دلیل
عوض کند.

## سه سؤال پایه

- دستگاه چه داده‌ای دارد؟ با **دیتاستریم** پاسخ دهید.
- این قرارداد برای کدام خانواده است؟ با **محصول یا Template** پاسخ دهید.
- کاربر چگونه آن را می‌بیند یا کنترل می‌کند؟ با **Experience و Studio** پاسخ دهید.

<Tip>
اول قرارداد داده و safety را مشخص کنید، بعد سراغ ظاهر داشبورد بروید.
</Tip>
