FlovaAI برای زمانی است که می‌دانید چه می‌خواهید، اما نمی‌خواهید برای رسیدن به
آن همهٔ مسیر Console را دستی طی کنید. می‌توانید دربارهٔ دستگاه، datastream،
دادهٔ تاریخی یا dashboard سؤال بپرسید و پاسخ را در همان زمینهٔ workspace بگیرید.

FlovaAI جای تصمیم‌گیری شما را نمی‌گیرد. در کارهایی که محصول را تغییر می‌دهند،
پیشنهاد باید قابل‌بررسی باشد و تغییر حساس تا قبل از تأیید شما اعمال نشود.
برای query نیز پاسخ باید بر اساس catalog واقعی و datastreamهای موجود باشد، نه
نامی که مدل حدس زده است.

## چه نوع درخواست‌هایی مناسب‌اند؟

```text
برای دستگاه‌های این Device Type یک خلاصه از datastreamهای خواندنی و نوشتنی بساز.
```

```text
دادهٔ دمای دستگاه آزمایشی را در ۲۴ ساعت اخیر به تفکیک ساعت خلاصه کن.
```

```text
یک automation پیشنهاد بده که وقتی دما از حد تعیین‌شده بالاتر رفت، رله را روشن کند.
قبل از اعمال، اجزای تغییر را نشان بده.
```

در prompt نام دقیق دستگاه و datastream را بنویسید. اگر چند مورد مشابه وجود
دارد، شناسه یا نام کامل را مشخص کنید و از AI بخواهید ابتدا گزینه‌ها را نشان دهد.

## ابزارها و عامل‌ها

نسخهٔ فعلی FlovaAI بر اساس مجوز workspace، قابلیت‌های موجود را در چند گروه به
کار می‌گیرد:

- خواندن فهرست Device Type، نسخه‌ها، datastreamها و mappingهای سخت‌افزاری
- دریافت catalog و اعتبارسنجی یا اجرای queryهای FlovaQL
- توضیح نتیجهٔ query به‌صورت جدول یا chart قابل‌فهم
- خواندن وضعیت و دادهٔ دستگاه و ارسال فرمان به datastream نوشتنی، در صورت داشتن مجوز
- پیشنهاد یا ویرایش Device Type، datastream و automation با مرحلهٔ بازبینی
- کمک به binding کردن داده به widgetهای dashboard

نام و دسترسی ابزارها ممکن است با مجوز کاربر یا تغییر محصول متفاوت باشد. FlovaAI
نباید به credential، schema داخلی یا source code دسترسی عمومی بدهد.

## چگونه prompt بهتری بنویسیم؟

هدف، محدوده و شکل پاسخ را در یک جمله روشن کنید. به‌جای «داده‌ها را بررسی کن»
بنویسید «میانگین `temperature` دستگاه X را در ۲۴ ساعت اخیر، ساعتی، در قالب
جدول برگردان». اگر درخواست شما تغییر ایجاد می‌کند، بنویسید «فقط پیشنهاد بده»
یا «قبل از اعمال، بازبینی نشان بده».

اگر پاسخ با دادهٔ شما جور نیست، آن را با نام دقیق و بازهٔ زمانی اصلاح کنید.
FlovaAI نباید برای پر کردن جای خالی، SQL یا field ساختگی تولید کند.
