# واژه‌نامه

| اصطلاح | معنی |
| --- | --- |
| Actor | هویت و scope مؤثر درخواست |
| Datastream | مسیر نام‌دار و typed برای یک مقدار |
| Device Link | مسیر ارتباطی دستگاه؛ جزئیات wire آن API عمومی نیست |
| Experience | تعریف صفحه‌ها، widgetها و bindingهای تجربه |
| FlovaAI | دستیار کنترل‌شده برای فهم و پیشنهاد تغییر در فضای کاری |
| FlovaQL | زبان معنایی و read-only برای دادهٔ فلووا |
| Provisioning | تحویل امن handoff و آماده‌سازی runtime دستگاه |
| Realtime ticket | credential کوتاه‌عمر مخصوص اتصال WebSocket |
| Template | قرارداد قابل‌انتشار خانوادهٔ دستگاه |
| Telemetry | مشاهده‌های دارای زمان از دیتاستریم‌ها |

معادل انگلیسی را در کد، API و log حفظ کنید؛ ترجمهٔ فارسی برای توضیح انسانی است.
