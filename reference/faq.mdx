# پرسش‌های پرتکرار

## آیا بدون کدنویسی می‌توانم شروع کنم؟

برای استفاده از محصول آماده بله. برای فریم‌ور سفارشی باید با C++، ابزار build
برد و safety سخت‌افزار آشنا باشید.

## آیا فلووا فقط برای ESP32 و ESP8266 است؟

این دو خانواده مسیر آماده دارند. هستهٔ قابل‌حمل SDK برای برد سفارشی، gateway و
محیط‌های غیر-Arduino نیز وجود دارد؛ transport و storage را برنامهٔ شما فراهم
می‌کند.

## چرا مقدار سنسور دیر دیده می‌شود؟

اتصال دستگاه، فاصلهٔ نمونه‌برداری، وضعیت presence و مقدارهای `reasonCode` را
بررسی کنید. ارسال سریع‌تر همیشه دادهٔ بهتری تولید نمی‌کند.

## چرا مقدار بعد از reboot روی عملگر اعمال نشد؟

Persistence ابتدا cache را بازیابی می‌کند. اعمال خودکار روی سخت‌افزار باید صریح،
ایمن و متناسب با محصول باشد؛ برای جزئیات [offline و persistence](/sdk/offline) را بخوانید.

## آیا credential را در کد قرار بدهم؟

خیر. credential، رمز Wi‑Fi و token را در source، screenshot یا log قرار ندهید.
