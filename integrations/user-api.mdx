# راهنمای User API

User API برای اپلیکیشنی است که با اجازهٔ یک کاربر روی دستگاه‌های claim‌شدهٔ او
کار می‌کند. مسیر پایهٔ عمومی `/api/user-app` است.

## ترتیب کلی

1. client و redirect URI دقیق را در Auth ثبت کنید.
2. authorization code با PKCE بگیرید.
3. token را با scope کمینه exchange کنید.
4. دستگاه را claim کنید یا دستگاه‌های claim‌شده را بخوانید.
5. برای command scope جداگانه و idempotency استفاده کنید.

```text
کاربر → authorize + code_challenge → callback
      → token exchange + code_verifier → User API
```

User token برای `/api/v1` معتبر نیست و organization machine token برای User API
معتبر نیست.
