# APIهای فلووا

فلووا دو مرز عمومی دارد:

| API | برای چه کسی؟ | اعتبار اصلی |
| --- | --- | --- |
| Organization API (`/api/v1`) | backend و automation سازمان | API key یا OAuth client credentials |
| User API (`/api/user-app`) | اپلیکیشن شخص ثالث به‌نمایندگی کاربر | OAuth Authorization Code + PKCE |

این دو مرز قابل‌جایگزینی نیستند. token یک API برای مسیر دیگر معتبر نیست.
