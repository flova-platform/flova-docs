# FlovaAI چیست؟

FlovaAI در کنار مدل محصول، دیتاستریم‌ها، داشبورد و automation کار می‌کند تا
کارهای تکراری را سریع‌تر کنید. نقش آن «حدس‌زدن سیستم» نیست؛ باید از context
قابل‌خواندن استفاده کند و تغییر را قابل‌بررسی نگه دارد.

## برای چه کارهایی مناسب است؟

- پیدا کردن مفهوم یا تنظیم مناسب در workspace
- پیشنهاد ساخت یا ویرایش template و datastream
- پیشنهاد mapping سخت‌افزار یا automation
- پیشنهاد تغییرات layout و binding در Studio
- توضیح خطا با نام انسانی و مسیر اصلاح

<Warning>
FlovaAI نباید credential بسازد، شناسه جعل کند، منبع ناشناخته را به‌عنوان داده
معرفی کند یا فرمان خطرناک را بدون تأیید انسان اجرا کند.
</Warning>
