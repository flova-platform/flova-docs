# افزودن و پایش دستگاه

## افزودن دستگاه

1. Template منتشرشده را انتخاب کنید.
2. دستگاه را با نام انسانی و metadata لازم بسازید.
3. activation code یا QR کامل را فقط در مسیر امن راه‌اندازی استفاده کنید.
4. پس از handoff، وضعیت provisioning را دنبال کنید.
5. وقتی generation تأیید شد، مقدار و فرمان ساده را آزمایش کنید.

قالب activation عمومی فلووا این است و URL نیست:

```text
FLOVA:ACTIVATE:1:<22-character-base64url-token>
```

کل payload را دقیقاً مصرف کنید؛ token خام، URL یا مقدار دارای فاصله معتبر نیست.

## پایش

در صفحهٔ دستگاه این موارد را کنار هم ببینید:

- presence و آخرین ارتباط
- مقدارهای فعلی دیتاستریم
- رخدادهای lifecycle و فرمان‌ها
- generation قرارداد و نسخهٔ فریم‌ور
- خطای آخر و `request_id` مربوط به آن

دستگاه آفلاین لزوماً خراب نیست؛ زمان آخرین مشاهده، وضعیت شبکه و گزارش runtime
را با هم بررسی کنید.
