title: "دستیار استودیو"
description: "با دستیار داخل استودیو ساختار داشبورد را بفهمید و تغییر دهید."
---

دستیار استودیو در پنل **دستیار** ویرایشگر قرار دارد. می‌تواند ساختار داشبورد را
بررسی کند، آن را توضیح دهد و برای تغییرهای پشتیبانی‌شده پیشنهاد بدهد. پیشنهاد را
پیش از اعمال بخوانید.

1. پنل دستیار را باز کنید.
2. نتیجهٔ موردنظر را با ذکر صفحه، ویجت، داده و چیدمان توضیح دهید.
3. اجازه دهید دستیار اطلاعات فعلی داشبورد را بخواند.
4. ویجت، اتصال و تغییر چیدمان پیشنهادی را بررسی کنید.
5. اگر دستیار پیش‌نمایش بصری ارائه کرد، پیش از اعمال پیشنهاد آن را بررسی کنید.
6. فقط وقتی پیشنهاد درست بود، آن را اعمال کنید.
7. داشبورد را در همهٔ اندازه‌های نمایش بررسی کنید.
8. آن را طبق روند معمول ذخیره و منتشر کنید.

درخواست «یک مقدار عددی برای دما، نمودار تاریخچه و کنترل نوشتنی پمپ اضافه کن»
از درخواست کلی دربارهٔ ظاهر داشبورد نتیجهٔ بهتری می‌دهد.

| بخش بررسی | پرسش |
| --- | --- |
| صفحه | صفحه و والد درست انتخاب شده‌اند؟ |
| ویجت | نوع ویجت برای مقدار یا کنش مناسب است؟ |
| اتصال | قالب، دستگاه، کلید و نوع مقدار درست هستند؟ |
| چیدمان | محتوا در موبایل، تبلت و دسکتاپ جا می‌شود؟ |
| ظاهر | ظاهر با پوسته و فاصلهٔ فعلی هماهنگ است؟ |
| کنش | کنش به منبع درست وصل است؟ |
| اعتبارسنجی | پیشنهاد از بررسی‌های موجود عبور کرده است؟ |

دستیار پیش از تغییر یک گرهٔ موجود باید اطلاعات فعلی داشبورد را بخواند. اگر نشست
دیگری داشبورد را تغییر داده است، اطلاعات تازه را بخوانید و پیشنهاد جدید بسازید.
اعمال پیشنهاد قدیمی ممکن است با تاریخچهٔ جدید سازگار نباشد.

دستیار داخل استودیو با برنامهٔ بیرونی تفاوت دارد. دستیار همان پنل گفت‌وگوی
استودیو است. برنامه‌های بیرونی از [Flova MCP](../mcp) استفاده می‌کنند و ورود،
OAuth و مجوزهای آن‌ها جداست.
