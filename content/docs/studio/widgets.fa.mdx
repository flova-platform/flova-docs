ویجت‌ها اجزای سازندهٔ داشبورد هستند. بعضی داده را نشان می‌دهند، بعضی ورودی
می‌گیرند و بعضی ویجت‌های دیگر را سازمان می‌دهند. ویجت را از پنل **ویجت‌ها**
اضافه کنید، روی بوم قرار دهید و سپس محتوا، داده، ظاهر و رفتار آن را در پنل
تنظیمات مشخص کنید.

| دسته | ویجت‌ها | کاربرد |
| --- | --- | --- |
| چیدمان | Area، Stack، Grid، Repeater | گروه‌بندی محتوا و ساختار تکرارشونده |
| محتوا | متن، آیکن، تصویر، HTML سفارشی | برچسب، تصویر، آیکن و نمایش سفارشی |
| داده | نشانگر، نمودار، جدول، لیست هشدارها | مقدار فعلی، تاریخچه، نتیجهٔ پرس‌وجو و هشدار |
| ورودی | کلید دوحالته، لغزنده، رنگ، شمارش معکوس، انتخاب‌گر، عدد، مدت‌زمان، ورودی متن، دکمه | ورودی کاربر و فرمان دستگاه |
| ناوبری | ناوبری | جابه‌جایی بین صفحه‌ها |
| لایهٔ شناور | شیت، کشو | نمایش محتوا روی صفحهٔ فعلی |

| ویجت | نقطهٔ شروع مناسب | نیاز معمول |
| --- | --- | --- |
| نشانگر | مقدار عددی یا بولی فعلی | اتصال سازگار و بازهٔ مناسب |
| نمودار | تله‌متری در یک بازهٔ زمانی | سری داده و منبع پشتیبانی‌شده |
| جدول | نتیجهٔ پرس‌وجو | پرس‌وجوی ذخیره‌شدهٔ FlovaQL و تنظیم ستون‌ها |
| لیست هشدارها | هشدار و رخداد دستگاه | محدوده و گزینه‌های نمایش |
| متن | عنوان، برچسب یا توضیح | متن و اتصال اختیاری |
| تصویر | تصویر محصول یا دستگاه | دارایی بارگذاری‌شده یا نشانی اینترنتی پشتیبانی‌شده |

ویجت ورودی را با نوع کانال هماهنگ کنید. برای بولی از کلید دوحالته، برای عدد از
لغزنده یا کنترل عدد، برای مقدار گزینه‌ای از انتخاب‌گر، برای فرمان رنگ از ویجت
رنگ، برای ثانیه از مدت‌زمان، برای متن از ورودی متن و برای کنش مستقل از دکمه
استفاده کنید.

دسترسی خواندن و نوشتن یکی نیست. ویجت ممکن است مقدار فقط‌خواندنی را نمایش دهد،
اما نتواند فرمان بفرستد. حالت دسترسی را در کنسول و اتصال را در استودیو بررسی
کنید.

## HTML سفارشی

ویجت HTML کد HTML، CSS و JavaScript را در محیط محدود اجرا می‌کند. استایل صفحهٔ
استودیو وارد آن نمی‌شود، پس استایل لازم را داخل خود ویجت بنویسید.

مقدارهای متصل از طریق `window.FlovaBridge` در دسترس هستند. جایگاه‌های اتصال با
نام‌های `input_0` تا `input_7` شماره‌گذاری می‌شوند.

~~~html
<script>
  const bridge = window.FlovaBridge;
  bridge.setCallbacks({
    onValueUpdated: (item) => {
      document.querySelector("#value").textContent = String(item?.value ?? "");
    },
  });
  bridge.getValue(0).then((item) => {
    document.querySelector("#value").textContent = String(item?.value ?? "");
  });
</script>
~~~

این ویجت به شبکه، فضای ذخیره‌سازی، فرم، اسکریپت بیرونی، شیوه‌نامهٔ بیرونی یا
قاب دسترسی ندارد. برای نمایش خطاهای ردشده از `onError` استفاده کنید. وقتی به
همهٔ ورودی‌ها یا تغییرهای پوسته نیاز دارید، `getValues()`، `getTheme()` و
`onThemeUpdated` در دسترس‌اند.

HTML سفارشی را مستقل نگه دارید. آن را با اتصال واقعی در پیش‌نمایش بررسی کنید و
سپس نسخهٔ منتشرشده را هم ببینید.

## افزودن ویجت

1. در ویجت‌ها بر اساس نام یا دسته جست‌وجو کنید.
2. ویجت را روی صفحه بکشید.
3. آن را روی بوم یا در لایه‌ها انتخاب کنید.
4. نامی توصیفی برای لایه بنویسید.
5. پیش از ظاهر، محتوا و داده را تنظیم کنید.
6. پیش‌نمایش و همهٔ اندازه‌های نمایش را بررسی کنید.
