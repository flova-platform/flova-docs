## Common widgets

| widget | Suitable for |
| --- | --- |
| status card | An important value and connection status
| toggle | read and write boolean state
| button | action or specific command
| gauge | Numeric value with interval and unit |
| line chart | Changes of one or more series in time
| text and input Description, label or user input
| alarm/event list | Logged events and warnings

## What is binding?

Binding is the link between the property of a widget and the data source. Source can be datastream
A Device Type is the selected device value or saved query from FlovaQL. for
Readable widget, datastream must be readable. For toggle, the value must be boolean
and the destination is writable. For charts, the query must return the time column and compatible series.
