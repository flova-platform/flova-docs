In Studio there are two important states: draft which is for your editing and published which is
The end user receives at runtime. Save the draft, the published version
does not change

## Release process

1. Edit widgets and pages in Studio.
2. Check the data bindings and actions from the Inspector.
3. In Preview, try the read and write paths.
4. Fix validation errors.
5. Review the version title and changes.
6. Confirm Publish.
7. Open dashboard in PWA or Android app with test device.

If dashboard uses saved FlovaQL query, the query at runtime with
Current access is executed. Saving a query does not create a new permission. If
datastream has been removed or retyped, fix incompatible binding before release
do
