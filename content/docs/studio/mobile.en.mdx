## Use PWA

1. Open `https://pwa.flova.ir` in the browser.
2. Log in to the account.
3. If the browser offers to install, select Add to Home Screen.
4. Open dashboard published and authorized device.
5. For provisioning, give necessary permissions and follow the steps to connect Wi-Fi.

PWA requires internet for page and data, but shell and cache can last
Keep the saved experience connected until you return. Live status and successful command
Only when you know for sure that the runtime has received the result.

## provisioning in mobile

In SoftAP, the app sends the device handoff from the local setup page. In BLE, the device app
Detects BLE, handsoff and Wi-Fi and then device to normal connection
returns If Wi-Fi automatic connection is not possible in Android version or browser, network
Select `Flova-Setup-*` manually and return to the app.

[provisioning Console](/en/docs/console/provisioning) activation steps page
and [provisioning SDK](/en/docs/sdk/provisioning) describes custom firmware boundaries.

## Device notifications

After the device is claimed, Flova sends a notification to the user. When the device
For the first time report a valid configuration and ready to use, separate notification
Another one is sent. Email is the primary channel, and if email is not available, verified
or sending error, SMS will be sent to the verified number.

Each notification has a button to open the same device in PWA and a link to the same guide.
If you get the device link with `device_id`, after login only the same authorized device
opens; Invalid link returns to device list. Device access from the side
Engine is checked and having a link alone does not create a license.
