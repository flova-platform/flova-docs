Studio is Flova's visual editor. You make dashboard like a product page, but
Values and commands come from Device Type and the selected device. This means the same
The experience can be implemented on the web, PWA and mobile app with a suitable layout for each page.

## The mentality of working with Studio

Split the page into two parts:

- Data that the user should see, such as the current value and its history
- Actions that the user must perform, such as changing the status, opening the page or selecting the device

In Studio, you select the page and widget first, then the data source or action in the Inspector
you choose Avoid setting a fixed value for device data; amount
Fixed is only suitable for help text, title and empty state.

## Preview and release

Preview is for checking layout and binding. Changes until publish
Don't be seen in the end user experience. Before publishing in mobile size and
Preview the desktop and try writing actions on a demo device.

## System pages

Built experience can be system screens or surfaces such as device selection,
Have Wi-Fi setting, timing and factory reset. These parts with dashboard
Normal are not the same, and the mobile host or PWA connects them to the real functionality of the device.
