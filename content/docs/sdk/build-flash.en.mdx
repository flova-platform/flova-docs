## universal
```sh
pio run -e universal-esp32
pio run -e universal-esp8266
```
For BLE version on ESP32:
```sh
pio run -e universal-esp32-ble
```
To flash directly with USB, add target upload:
```sh
pio run -e universal-esp32 -t upload
pio device monitor -b 115200
```
Match the environment name with the actual board. A ESP32 image on ESP8266
Do not flash; their target, memory and path OTA are different.

## custom Arduino

Create an existing program example with a suitable profile:
```sh
pio run -e custom-arduino-client-esp32
pio run -e custom-arduino-client-esp8266
```
To test datastream:
```sh
pio run -e datastream-api-esp32
pio run -e datastream-api-esp8266
```
Before uploading, compare the keys datastream and mapping with Device Type. none
Do not put the device ID, token or secret in the sketch.

## custom board

The portable example is built with CMake:
```sh
cmake -S . -B /tmp/flova-firmware-host-build
cmake --build /tmp/flova-firmware-host-build
ctest --test-dir /tmp/flova-firmware-host-build --output-on-failure
```
