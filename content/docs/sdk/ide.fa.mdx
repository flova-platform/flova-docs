[Flova IDE](https://console.flova.ir/ide) ویرایشگر Firmware در مرورگر است.
Build روی فلووا انجام می‌شود؛ آپلود USB و مانیتور سریال از بردی استفاده
می‌کنند که به رایانهٔ شما وصل است. برای ابزارهای محلی، [راهنمای نصب](../install/) را ببینید.

## ساخت پروژه و Build

۱. وارد کنسول شوید، فضای کاری را انتخاب کنید و **IDE** را باز کنید. برای
ایجاد، ویرایش یا Build پروژه به دسترسی مدیریت پروژه نیاز دارید.

۲. با نمونهٔ مخصوص برد خود شروع کنید. برای نگاشت سخت‌افزار از روی قالب،
**Universal** و برای نوشتن Handler کنترل GPIO، **LED starter** را انتخاب کنید.
نمونه، فایل‌ها و تنظیمات را کپی می‌کند اما نوع دستگاه ایجاد یا متصل نمی‌کند.
نوع دستگاه را با کلیدها و نوع داده‌های دقیق نمونه منتشر کنید.

۳. پیش از Build، فایل `platformio.ini` را بررسی کنید. پلتفرم، برد و چارچوب
Arduino در این فایل تعیین می‌شوند. وابستگی‌ها و وابستگی‌های غیرمستقیم باید
نسخهٔ دقیق Registry داشته باشند، نه بازه‌ای با `^`. نسخهٔ SDK نمونه را فقط
برای ارتقای آگاهانه تغییر دهید. اسکریپت اضافی و URL خارجی برای بسته‌ها پشتیبانی نمی‌شود.

۴. **Build** را بزنید. اگر خطایی رخ داد، خروجی Build را باز کنید و از
**Problems** به خط کد بروید. تعداد پروژه‌ها و Buildها تابع پلن فضای کاری است.

## آپلود و بررسی برد

۱. از مرورگر دسکتاپ دارای Web Serial، مانند Chrome یا Edge، استفاده کنید.
برد را با کابل USB داده وصل کنید و سایر مانیتورهای سریال را ببندید.

۲. Build موفق را آپلود کنید و به مرورگر اجازهٔ دسترسی به پورت برد را بدهید.
اگر برد وارد Bootloader نشد، دستور آپلود سازندهٔ برد را دنبال کنید. برای فلش
محلی می‌توانید فایل‌ها را دانلود کنید؛ از آدرس‌های فلش همان هدف استفاده کنید،
نه ترتیب فایل‌ها.

۳. مانیتور سریال را باز کنید و نرخ Firmware را تنظیم کنید (معمولاً `115200`).
آپلود موفق به معنی آنلاین بودن برد نیست. [راه‌اندازی](../provisioning/) را کامل
کنید و سپس وضعیت دستگاه و اولین مقدار پذیرفته‌شده را در کنسول بررسی کنید.

فایل‌هایی را که نیاز دارید دانلود کنید؛ فایل‌ها و گزارش‌های Build موقت‌اند
و معمولاً پس از هفت روز منقضی می‌شوند. Build خودکار به‌عنوان
[نسخهٔ OTA](../lifecycle/) منتشر نمی‌شود.
