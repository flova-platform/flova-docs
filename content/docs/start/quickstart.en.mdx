title: "Quick start: control an ESP32 built-in LED"
description: "Connect an ESP32 to Flova and control its built-in LED from a dashboard in about ten minutes."
icon: rocket
---
This guide connects an ESP32 to Flova and switches its built-in LED from a dashboard. You need an ESP32 board with an LED on `GPIO2`, a USB data cable, a phone or computer with Wi-Fi, and PlatformIO.

## 1. Create an account and Device Type

Open the [Flova Console](https://console.flova.ir/) and create an account. Create a Device Type named `ESP32 LED` and choose Wi-Fi as its setup method.

Add a datastream with these values:

| Field | Value |
| --- | --- |
| Name | Internal LED |
| Technical key | `LED` |
| Value type | Boolean |
| Access | Read/write |
| Behavior | Digital output |
| Hardware pin | `GPIO2` |
| Active level | HIGH |
| Default and safe value | Off |

Use the technical key `LED` exactly. The same key connects the dashboard to the device later. Publish the Device Type version; a device cannot be created from an unpublished version.

## 2. Flash universal firmware

Clone [Flova Firmware](https://github.com/flova-platform/flova-firmware), open the `examples/universal-esp32` example, and connect the board over USB. The example already contains a minimal program:

```cpp
#include <Arduino.h>
#include <FlovaSDK.h>

FlovaUniversalEsp32 device;

void setup() {
  Serial.begin(115200);
  device.begin();
}

void loop() {
  device.run();
}
```

From the firmware repository, run:

```bash
pio run -e universal-esp32 -t upload
```

On its first run, the firmware creates a temporary network named like `Flova-Setup-*`. Wi-Fi credentials are entered during setup; they do not belong in the source code.

## 3. Create the device and activation code

In Console, open the Devices page for the same Device Type and choose **Add Device**. Give it a name and create the device. Console displays a one time activation QR and a manual code.

Keep the QR payload private. The activation contract is `FLOVA:ACTIVATE:1:<22-character token>`.

## 4. Activate it in the PWA

Open the [Flova web app](https://pwa.flova.ir/) and sign in to the same account. Choose **Add device**, scan the QR code, name the device, and confirm activation.

If the camera is unavailable, choose **Manually enter the activation code** and enter only the 22 character token. Do not enter the `FLOVA:ACTIVATE:1:` prefix in the manual field; that prefix belongs to the complete QR payload.

Activation assigns the device to your account. It does not configure Wi-Fi yet.

## 5. Send Wi-Fi settings

When the PWA enters setup mode, connect the phone or computer to the network whose name starts with `Flova-Setup-`. Return to the PWA, enter the normal Wi-Fi name and password, and submit the form.

The local setup page sends the network settings to the ESP32. After the device accepts them, reconnect the phone or computer to its normal network. The ESP32 saves the settings, restarts, and connects to Flova. In Console its status should move through setup and sync to online.

If the PWA cannot find the board, confirm that the browser is still connected to `Flova-Setup-*` and that the device and browser are on the same local network.

## 6. Build the LED dashboard

Open [Studio](https://studio.flova.ir/) and create a dashboard from the `ESP32 LED` Device Type. Add a **Toggle** and connect it to the `LED` datastream. Publish the dashboard.

Open the device in the PWA and change the toggle. The `LED` command travels through FlovaLink and universal firmware applies it to `GPIO2`.

## If something fails

If the device never comes online, check the setup network, then check the Wi-Fi credentials and the device status in Console. If the toggle does not change, verify that the Device Type version is published and that the `LED` key matches in Console and Studio. Continue with the [troubleshooting guide](/en/docs/support/troubleshooting).
