# From idea to connected product

Flova is a set of tools for building products that work with real devices. In Console, you define the type of device and data channels, put the firmware on the board, transfer data and command with FlovaLink, and in Studio you create an experience that the user sees on mobile or in a browser.

<Note>
This documentation is written for actual use. Complete the examples with your own account, device, and datastream, and do not include any real credentials.
</Note>

## Suggested route

1. Read [Flova's mental model](/en/docs/start/mental-model).
2. Build [The first device](/en/docs/start/quickstart).
3. Define [Datastreams](/en/docs/concepts/datastreams) with specified convention.
4. Run [Firmware SDK](/en/docs/sdk/quickstart) on the board.
5. Build [The first query](/en/docs/flovaql/examples) or [The first dashboard](/en/docs/studio/dashboards).
