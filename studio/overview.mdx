# استودیو فلووا

Studio تجربهٔ کاربری محصول را می‌سازد: صفحه، layout، widget، binding و
navigation. دادهٔ واقعی از Template و Device می‌آید؛ Studio منبع truth آن نیست.

## مرزهای مهم

- Template قرارداد دیتاستریم را تعریف می‌کند.
- Studio widget را به یک منبع معتبر وصل می‌کند.
- Runtime مقدار را با همان نوع و semantics نمایش می‌دهد.
- کاربر باید بتواند loading، stale، offline و خطا را بفهمد.

برای شروع، [اولین داشبورد](/recipes/first-dashboard) را بسازید و سپس به
[bindingها](/studio/bindings) بروید.
