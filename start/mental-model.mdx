# مدل ذهنی فلووا

فلووا چند لایهٔ جدا اما متصل دارد:

```text
محصول / Template
  └── تعریف دیتاستریم و رفتار
        └── دستگاه واقعی / Device
              └── گزارش، فرمان و تله‌متری
                    ├── FlovaQL برای خواندن داده
                    ├── Automation برای واکنش
                    └── Studio برای ساخت تجربه
```

## چه چیزی کجا زندگی می‌کند؟

| مفهوم | پاسخ کوتاه |
| --- | --- |
| Workspace / سازمان | مرز مالکیت، اعضا، credential و محدودیت‌ها |
| Product / Template | قرارداد مشترک یک خانوادهٔ دستگاه |
| Device | یک نمونهٔ واقعی با چرخهٔ عمر و وضعیت مستقل |
| Datastream | مسیر نام‌دار یک مقدار typed |
| Telemetry | تاریخچهٔ مشاهده‌های زمانی |
| Experience | صفحه و رفتار کاربری ساخته‌شده در Studio |
| Automation | قاعدهٔ واکنش به رویداد یا مقدار |

Console برای مدل و عملیات است؛ SDK برای رفتار دستگاه؛ Studio برای تجربه؛ API و
FlovaQL برای اتصال نرم‌افزارها به داده و کنترل.
