# شروع سریع

برای شروع یک سنسور و یک خروجی ساده کافی است. این مسیر از مدل‌سازی تا مشاهدهٔ
اولین مقدار را پوشش می‌دهد.

## پیش‌نیازها

- یک حساب و workspace در فلووا
- یک برد ESP32 یا ESP8266
- PlatformIO و کابل داده برای توسعهٔ فریم‌ور
- دسترسی به Wi‑Fi در زمان provisioning

## چهار گام اصلی

### ۱. محصول را تعریف کنید

محصول، قرارداد مشترک خانواده‌ای از دستگاه‌هاست. برای نمونه، یک محصول
«کنترلر گلخانه» می‌تواند دیتاستریم‌های `temperature`، `humidity` و `pump` را
داشته باشد.

### ۲. دیتاستریم‌ها را بسازید

برای هر مقدار، نوع، جهت و معنای آن را مشخص کنید. کلید فنی را کوتاه، پایدار و
انگلیسی انتخاب کنید؛ عنوان فارسی فقط برای نمایش است.

### ۳. فریم‌ور را اجرا کنید

در [نصب SDK](/sdk/install) وابستگی را اضافه کنید و در [شروع سریع فریم‌ور](/sdk/quickstart)
یک `report` برای سنسور یا `write` برای عملگر بسازید.

### ۴. دستگاه را provision کنید

دستگاه را از مسیر رسمی راه‌اندازی به محصول وصل کنید. credential را داخل سورس
نویسید؛ دستگاه باید handoff کوتاه‌عمر را دریافت کند و secret خودش را بسازد.

<Warning>
موفقیت build یا روشن‌شدن LED به‌تنهایی به معنی online شدن دستگاه نیست. وضعیت
provisioning، generation پیکربندی و اولین مقدار را هم بررسی کنید.
</Warning>
