# دیتاستریم‌ها

دیتاستریم یک کلید پایدار برای یک مقدار است؛ مثل `temperature`، `humidity` یا
`relay`.

| نوع رفتار | مسیر معمول | نمونه |
| --- | --- | --- |
| مشاهده | دستگاه به فلووا گزارش می‌دهد | `temperature.report(24.8)` |
| فرمان | فلووا به دستگاه مقدار می‌نویسد | `relay.write(true)` |
| دوطرفه | هر دو مسیر با safety روشن | وضعیت شیر یا قفل |

## قواعد نام‌گذاری

- کلید را انگلیسی، کوتاه و پایدار انتخاب کنید.
- کلید را با label فارسی یکی نکنید؛ label قابل تغییر است.
- نوع را با مقدار واقعی هماهنگ کنید: `boolean`، `double` یا `string` در قرارداد
  عمومی Engine.
- برای واحد و معنای مقدار توضیح روشن بنویسید.

## یک قرارداد نمونه

```json
{
  "key": "temperature",
  "type": "double",
  "unit": "°C",
  "readable": true,
  "writable": false
}
```

جزئیات اجرای callback و سیاست offline در [راهنمای SDK](/sdk/datastreams) آمده است.
