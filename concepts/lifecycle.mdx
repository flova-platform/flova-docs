# چرخهٔ عمر دستگاه

چرخهٔ عمر دستگاه فقط «آنلاین یا آفلاین» نیست:

1. **ساخت**: دستگاه برای یک محصول ایجاد می‌شود.
2. **Activation**: handoff کوتاه‌عمر از مسیر رسمی دریافت می‌شود.
3. **Provisioning**: credential و قرارداد پیکربندی به‌شکل معتبر ثبت می‌شوند.
4. **Verifying runtime**: دستگاه پس از reboot قرارداد را بررسی و گزارش می‌کند.
5. **Online**: heartbeat، state و فرمان‌ها در دسترس‌اند.
6. **Update یا archive**: نسخهٔ فریم‌ور، پیکربندی یا وضعیت مالکیت تغییر می‌کند.

<Note>
ثبت credential به‌تنهایی provisioning موفق نیست. پس از reboot، گزارش پیکربندی
باید با generation مورد انتظار منطبق باشد.
</Note>
